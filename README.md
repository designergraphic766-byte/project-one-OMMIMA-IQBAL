# DecodeLabs Internship - Travel Explorer Website

This repository contains the Travel Explorer web application developed during the DecodeLabs Frontend Development Internship.

## 🚀 Project Overview
A fully responsive travel and destination showcase website designed with modern HTML5 and CSS3 styling, featuring a custom hero banner, travel destination grid cards, and an interactive footer layout.

## ✨ Key Features
- **Responsive Navigation Header:** Clean layout featuring a brand logo and navigation links[cite: 2, 3].
- **Hero Section:** Eye-catching banner overlay with custom typography, welcome heading, and call-to-action button[cite: 2, 3].
- **Destination Grid Gallery:** CSS Grid-based layout showcasing popular international destinations (Paris, Malaysia, Singapore, Dubai, and more) with custom cards[cite: 2, 3].
- **Responsive Design:** Custom media queries to ensure smooth scaling across desktop, tablet, and mobile devices[cite: 3].

## 🛠️ Tech Stack
- **HTML5** (Semantic structure)[cite: 2]
- **CSS3** (Custom CSS variables, Grid, Flexbox, and Media Queries)[cite: 3]

## 📂 How to View
1. Clone this repository or download the ZIP file.
2. Ensure image assets (such as `logoo.png`, `banner.jpg`, and destination images) are in the root directory.
